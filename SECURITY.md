# Security policy

## Supported versions

Dunlin is an experimental inference research project. Security fixes target the
latest release. Older releases do not receive separate security maintenance;
you may be asked to update when reporting an issue.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting page](https://github.com/mczhu/dunlin/security/advisories/new).
You can also find this through **Security → Advisories → Report a vulnerability**.
Do not include vulnerability details, credentials, or sensitive data in public
issues or pull requests.

Include:

- The affected release or commit and relevant environment details.
- A description of the issue and its potential impact.
- Minimal steps or a proof of concept to reproduce it, with secrets removed.

Reports are reviewed on a best-effort basis. There is no guaranteed response or
resolution timeline. Please coordinate public disclosure with the maintainer.

For ordinary bugs, benchmark discrepancies, or feature requests, use
[GitHub Issues](https://github.com/mczhu/dunlin/issues).
